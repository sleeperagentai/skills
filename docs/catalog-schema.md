# `catalog.json`

Generated by `python3 -I scripts/build-catalog.py`. Never edit by hand; CI fails if it is stale.
Deterministic output (sorted keys, no timestamps) so `--check` is stable.

```json
{
  "schema_version": 1,
  "repo": "sleeperagentai/skills",
  "default_branch": "main",
  "categories": { "<key>": "<description>" },
  "counts": { "skills": 0, "collections": 0, "plugins": 0 },
  "skills": [
    {
      "kind": "skill",
      "name": "impeccable",
      "category": "design",
      "category_label": "UI, UX, ...",
      "path": "skills/design/impeccable",
      "description": "...",
      "license": "Apache-2.0",
      "compatibility": "",
      "tags": ["design", "ui"],
      "aliases": [],
      "triggers": [],
      "vendored": true,
      "added": "2026-11-03",
      "source": { "type": "github", "repo": "pbakaus/impeccable", "path": ".agents/skills/impeccable", "commit": "..." },
      "install": { "project": "npx -y skills add sleeperagentai/skills --skill impeccable -y", "global": "... -g -y" }
    }
  ],
  "collections": [ { "kind": "collection", "name": "...", "repo": "owner/repo", "description": "...", "install": { } } ],
  "plugins":     [ { "kind": "plugin",     "name": "...", "repo": "owner/repo", "description": "...", "install": { } } ]
}
```

`skills[]` entries merge the frontmatter (`description`, `license`, `compatibility`, Hermes
`metadata.hermes.tags`) with `metadata.json` (which wins on overlap). `collections[]` and
`plugins[]` are the pointer JSON files verbatim plus `kind` and `path`.
