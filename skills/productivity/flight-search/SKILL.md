# Flight Search Skill

## Purpose
Find the cheapest direct flights between two airports on specific dates, while navigating common anti-bot protections (CAPTCHAs, consent walls, bot detection pages) that automated tools often trigger.

## When to Use
- User wants to locate low‑cost flights for a given route and date(s).
- User prefers direct flights only.
- User wants ready‑to‑click booking links or price‑alert setup.

## Steps

1. **Prepare search URLs**  \n   Use pre‑filled links from major aggregators that already include origin, destination, and date:\n   - Google Flights: `https://www.google.com/travel/flights?q=Flights+from+<ORIGIN>+to+<DEST>+on+<YYYY-MM-DD>`\n   - Skyscanner: `https://www.skyscanner.net/transport/flights/<ORIGIN>/<DEST>/<YYYYMMDD>/?adults=1&cabinclass=economy`\n   - Kiwi.com: `https://www.kiwi.com/en/search/results/<ORIGIN>-<DEST>/<YYYY-MM-DD>`\n\n   Replace `<ORIGIN>` with IATA code (e.g., `LHR`), `<DEST>` with destination code (e.g., `YYZ`), and `<YYYY-MM-DD>` with the travel date.\n   \n   **Tip**: Use the template file `templates/flight-search-links.txt` for ready-to-use URL formats.\n\n2. **Open in a private/incognito browser window**  \n   This prevents price inflation from cookies and reduces bot‑triggering signals.\n   \n   **Note**: Even automated browser control (like Playwright or Selenium) can trigger bot detection on some sites, requiring manual intervention for consent pages or CAPTCHAs.\n\n3. **Handle consent/CAPTCHA pages**  \n   - If a consent dialog appears (e.g., Google’s “Before you continue”), click “Accept all” or “Reject all” as preferred.  \n   - If a CAPTCHA or bot‑check page appears (e.g., “Show us your human side…”, “Are you a person or a robot?”), solve it manually.  \n   - After clearing the obstruction, the site will display the flight results.\n   \n   **Site-specific observations**:\n   - Google Flights: Often shows a consent page requiring a click to proceed.\n   - Skyscanner: May present CAPTCHA challenges under high traffic or automated access.\n   - Momondo/CheapOair: Tend to show immediate "Access Denied" for automated tools.\n   - Kiwi.com: Generally more cooperative with form filling and search submission via automation.\n\n4. **Filter for direct flights only**  \n   - On Google Flights: click “Stops” → select “Nonstop”.  \n   - On Skyscanner: use the “Stops” filter → “Direct”.  \n   - On Kiwi.com: enable the “Non‑stop” toggle.\n\n5. **Sort by price**  \n   Ensure results are ordered from lowest to highest price. Note the cheapest option that meets the user’s budget (e.g., < £400).\n\n6. **Extract booking link**  \n   - Right‑click the flight entry → “Copy link” or use the “Select” button to open the airline/OTA page.  \n   - Provide the direct booking URL to the user.\n\n7. **Optional: Set price alerts**  \n   - On Google Flights: toggle “Track prices”.  \n   - On Skyscanner: click “Get price alerts”.  \n   - On Kiwi.com: use the “Alert” button.  \n   This emails the user when the price drops.\n\n8. **If blocked, try an alternative site**  \n   If one aggregator presents a significant block (e.g., persistent CAPTCHA, access denied), move to another site from your list (Google Flights → Skyscanner → Kiwi.com) and repeat the process.\n\n## Pitfalls & Workarounds\n- **Bot detection blocks automated scrapers** – Most flight aggregators serve a bot‑check page to headless browsers. The reliable workaround is to use a real browser (manual solve) or rely on the site’s own UI via pre‑filled links as above.\n- **Even browser automation can trigger detection** – Advanced bot detection may identify automated browser frameworks (Playwright, Selenium, etc.). Be prepared to manually solve consent pages or CAPTCHAs.\n- **Site-specific blocking patterns** – Different aggregators employ different anti-bot strategies:\n  - Consent walls: Common on Google services (Google Flights)\n  - CAPTCHA/challenges: Skyscanner, Kiwi.com (under stress)\n  - Hard blocking: Momondo, Cheapoair (often immediate for automation)\n  - Adaptive approach: Have a preferred order of sites to try based on current blocking behavior.\n- **Price fluctuation** – Prices can change minute‑by‑minute. Advise the user to book quickly once a satisfactory fare is found.\n- **Alternative airports** – If direct flights are too expensive, consider nearby airports (e.g., YTZ, YHM for Toronto) and repeat the search.\n- **Currency display** – Ensure the site shows prices in GBP (£) if the user’s budget is in pounds; switch currency in site settings if needed.\n\n## Verification\n- Verify that the returned flights are nonstop by checking the “Stops” column.\n- Confirm the total price includes taxes and fees (most aggregators show the final price).\n\n## References\n- `references/bot-detection.md` – notes on common bot‑check pages and how to bypass them manually.\n- `templates/flight-search-links.txt` – template for generating the three base URLs with examples.
